# Code-formatter

привет это новая моя программа! скачать exe файл можно в релизах!
как использовать программу??

создаем папку и помещаем туда наш C++ код а точнее так *название вашего файла*.cpp и программу .exe которую скачали в релизах
дальше нажимаем по пустому месту в папке и открыть в терминале
дальше пишем .\code_formatter.exe "*название вашего файла*.cpp"
и нажимаем enter дальше получаем все о нашем коде и об ошибках в конце статистика кода.

пример:
.\code_formatter.exe "test.cpp"
